# 떠나요

국내 여행의 장소를 저장하고 화이트보드형 일정판에서 동선을 만드는 웹서비스입니다.

## 현재 구조

| 폴더 | 역할 |
|---|---|
| `tteonayo` | React 19, TypeScript, Vite, React Router, Tailwind CSS, Leaflet |
| `tteonayo-server` | Express 5, JWT 로그인, lowdb 파일 저장 |

여행 데이터는 로그인 사용자별로 서버의 `tteonayo-server/tteonayo.json`에 저장됩니다. 브라우저 저장소는 기존 데이터 가져오기와 복구용 백업으로 사용합니다. 사진은 현재 일정판 데이터 안에 압축된 이미지로 저장되며, 별도의 Storage 서비스는 아직 연결되지 않았습니다.

## 로컬 실행

터미널 두 개에서 각각 실행합니다.

```bash
cd tteonayo-server
npm install
npm start
```

```bash
cd tteonayo
npm install
npm run dev
```

프런트엔드가 표시한 로컬 주소로 접속해 로그인합니다. 서버의 기본 포트는 `4000`입니다. `tteonayo-server/.env`에 `PORT`와 `JWT_SECRET`을 설정할 수 있습니다. 개발 중 `JWT_SECRET`이 없으면 서버가 무작위 키를 생성해 로컬 DB에 저장하며, 운영 환경에서는 환경변수가 필수입니다. 기존 개발용 고정 키로 발급된 토큰은 다시 로그인해야 할 수 있습니다.

서버 환경변수 예시는 `tteonayo-server/.env.example`에 있습니다. 같은 폴더에 `.env`로 복사해 사용하세요. 예시에서 `연결 예정`이라고 표시된 카카오·OpenAI·숙소·혼잡도·경로·Supabase 키는 현재 코드에서 읽지 않으므로, 키를 입력해도 해당 기능이 바로 켜지지는 않습니다. 실제 키를 `.env.example`이나 프런트엔드 코드에 적지 마세요.

## 기존 브라우저 데이터

로그인 후 해당 계정의 서버 데이터가 비어 있으면 기존 장소·일정판·채팅 데이터를 한 번 가져옵니다. 같은 가져오기 요청은 중복 반영되지 않습니다. 서버와 브라우저의 데이터가 서로 다르고 안전하게 합칠 수 없으면 자동으로 덮어쓰지 않습니다. 이때 화면에서 브라우저 데이터를 JSON으로 백업한 뒤 서버 데이터를 열 수 있습니다. 서로 다른 내용의 자동 병합·백업 파일 재가져오기는 아직 지원하지 않습니다.

## 현재 기능과 제약

- 지도: OpenStreetMap/Overpass 장소 조회, 저장·수정·삭제, 직접 추가. 공개 장소 데이터는 누락되거나 조회가 지연될 수 있습니다. 카카오맵 키와 실제 연동은 없습니다.
- 일정판: 왼쪽 날짜별 일정 목록과 중앙 화이트보드에서 저장 장소·메모·사진 카드, 카드 위치, 연결선을 편집합니다. 방문 순서와 카드 위치는 별도로 저장됩니다. 상단에 입력된 비용 합계와 예산을 표시하고, 여행 설정과 카드 상세는 필요할 때 엽니다. 서버 저장·다시 열기와 브라우저 인쇄를 통한 PDF 저장을 지원합니다. 기존 날짜 없는 장소 카드는 `미분류`로 보존합니다.
- 기록함: 저장한 일정판 열기·삭제, 공유 안내 UI. 실제 링크 공유와 공동 편집은 없습니다.
- 채팅: 지역별 질문 기록을 서버에 저장하고 Open-Meteo 현재 날씨를 조회합니다. AI 답변, 관광지 혼잡도, 숙소 평균 가격은 아직 제공되지 않습니다.
